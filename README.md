# تطبيق مصروفاتي (تطبيق ويب)

الملفات:
- index.html  : التطبيق نفسه
- manifest.webmanifest : بيخلي الموبايل يتعامل معاه كتطبيق
- sw.js : بيخليه يشتغل من غير نت
- icon-180.png / icon-192.png / icon-512.png : الأيقونات

مهم: ارفع الملفات دي مع بعض في نفس المكان، من غير ما تغيّر أسماءها.

## الطريقة الأولى: GitHub Pages (مجاني، الأسهل من كمبيوتر)
1. اعمل حساب على github.com.
2. New repository، اكتب اسم زي masrofaty، واختار Public، وبعدين Create.
3. Add file ثم Upload files، وارفع الملفات الستة (الملفات نفسها، مش الـ zip)، وبعدين Commit changes.
4. Settings ثم Pages، واختار Branch: main ومعاه root، وبعدين Save.
5. بعد دقيقة أو اتنين يظهر لينك شكله: https://اسمك.github.io/masrofaty/

## الطريقة التانية: Netlify
1. افتح app.netlify.com/drop وسجّل بحساب.
2. اسحب فولدر الملفات (بعد فك الضغط) على الصفحة.
3. هتاخد لينك. لو سبت الموقع من غير حساب ممكن يتمسح.

## تثبيته على الموبايل
- آيفون: افتح اللينك في Safari، وبعدين زرار المشاركة، وبعدين Add to Home Screen، وبعدين Add.
- أندرويد: افتحه في Chrome، وبعدين النقط التلاتة، وبعدين Add to Home screen أو Install app.

## ملاحظات
- افتح التطبيق دايمًا من الأيقونة. على الآيفون بيانات الأيقونة منفصلة عن بيانات Safari.
- البيانات بتتخزن على موبايلك بس، ومش بتنتقل من لينك لتاني.
- لو عدلت index.html وارفعته تاني، التحديث بيوصل لما تفتح التطبيق وفيه نت.
- الخط العربي بيتحمل من الإنترنت، ومن غير نت بيستخدم خط الموبايل العادي.
